Gather and confirm understanding the commit before beginning implementation work.

## Process

### 1. Read Commit diff

Take a look to commit `$ARGUMENTS` changes and commit message.

### 2. Confirm Understanding

After reading the commit diff:

- Summarize the changes
- Confirm understanding what was changed
- Identify any unclear areas
- Prepare for implementation work

## Purpose

This command ensures context awareness before starting implementation. Subsequent messages will involve working on similar areas the commit touched.

**Mode**: Read-only context gathering. No code changes in this command.
